# 《谢凡的奇幻冒险2.0》技术设计文档

## 1. 技术选型

### 1.1 核心技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | 原生 HTML/CSS/JS | 零依赖，轻量，易于部署 |
| UI框架 | Tailwind CSS (CDN) | 快速样式开发 |
| 动画 | CSS Animation + Animate.css | 过渡效果 |
| 存储 | localStorage | 本地存档 |
| 构建 | 无构建 | 单文件或少量文件直接运行 |
| 部署 | GitHub Pages / Vercel | 静态托管，零成本 |

### 1.2 为什么不用游戏引擎

- **Twine**: 太重，学习成本高，样式定制困难
- **Ren'Py**: Python环境依赖，不适合Web
- **Unity**: 杀鸡用牛刀，2D文字游戏不需要
- **原生前端**: 最灵活，最容易控制，玩家无需安装

### 1.3 可选增强

| 需求 | 方案 | 是否必须 |
|------|------|---------|
| 打字机效果 | Typed.js 或 自实现 | 可选 |
| 粒子效果 | particles.js | 可选 |
| 音频 | Howler.js | 可选 |
| 存档导出 | FileSaver.js | 可选 |

### 1.4 纯CSS实现方案

**零美术资源，代码即艺术**

所有游戏视觉元素（场景、角色、特效、UI）完全使用HTML+CSS实现，不依赖任何图片资源。

**详细方案**：[纯CSS实现方案](./纯CSS实现方案.md)

**核心优势**：
- 零资源加载，启动速度极快
- 完全可控，所有视觉效果通过代码调整
- 响应式完美，CSS轻松适应不同屏幕尺寸
- 风格统一，不会出现美术资源风格不一致
- 维护简单，修改CSS即可，无需重新设计图片
- 文件体积小，纯代码，无图片资源

**适用场景**：
- 视觉小说游戏
- 文字冒险游戏
- 简约风格游戏
- 独立游戏
- 原型开发

## 4. 游戏引擎设计

### 4.1 核心类

```javascript
class GameEngine {
  constructor() {
    this.state = null;
    this.currentNode = null;
    this.isAutoPlaying = false;
  }
  
  // 初始化游戏
  init() {
    this.loadState();
    this.render();
    this.bindEvents();
  }
  
  // 加载剧情节点
  loadNode(nodeId) {
    this.currentNode = storyNodes[nodeId];
    this.state.currentNode = nodeId;
    this.render();
  }
  
  // 渲染当前节点
  render() {
    this.renderBackground();
    this.renderDialogue();
    this.renderChoices();
    this.renderUI();
  }
  
  // 处理选择
  makeChoice(choiceId) {
    const choice = this.currentNode.choices.find(c => c.id === choiceId);
    if (!choice) return;
    
    // 应用效果
    this.applyEffects(choice.effects);
    
    // 跳转
    this.loadNode(choice.nextNode);
    
    // 自动存档
    this.autoSave();
  }
  
  // 应用效果
  applyEffects(effects) {
    if (effects.attributes) {
      Object.keys(effects.attributes).forEach(attr => {
        this.state.attributes[attr] += effects.attributes[attr];
      });
    }
    if (effects.flags) {
      Object.keys(effects.flags).forEach(flag => {
        this.state.flags[flag] = effects.flags[flag];
      });
    }
    if (effects.relationships) {
      Object.keys(effects.relationships).forEach(npc => {
        this.state.relationships[npc] += effects.relationships[npc];
      });
    }
  }
  
  // 自动播放
  async autoPlay() {
    if (!this.currentNode.autoNext) return;
    
    this.isAutoPlaying = true;
    await this.delay(this.currentNode.autoDelay);
    
    if (this.isAutoPlaying) {
      this.loadNode(this.currentNode.autoNext);
    }
  }
  
  // 延迟函数
  delay(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

### 4.2 存档系统

```javascript
class SaveSystem {
  // 保存
  static save(slot = 'auto') {
    const saveData = {
      state: gameState,
      timestamp: Date.now(),
      version: '2.0'
    };
    localStorage.setItem(`phd_save_${slot}`, JSON.stringify(saveData));
  }
  
  // 读取
  static load(slot = 'auto') {
    const data = localStorage.getItem(`phd_save_${slot}`);
    if (!data) return null;
    
    const saveData = JSON.parse(data);
    return saveData.state;
  }
  
  // 删除
  static delete(slot = 'auto') {
    localStorage.removeItem(`phd_save_${slot}`);
  }
  
  // 导出
  static export(slot = 'auto') {
    const data = localStorage.getItem(`phd_save_${slot}`);
    const blob = new Blob([data], { type: 'application/json' });
    const url = URL.createObjectURL(blob);
    
    const a = document.createElement('a');
    a.href = url;
    a.download = `phd_adventure_save_${Date.now()}.json`;
    a.click();
    
    URL.revokeObjectURL(url);
  }
  
  // 导入
  static import(file) {
    return new Promise((resolve, reject) => {
      const reader = new FileReader();
      reader.onload = (e) => {
        try {
          const saveData = JSON.parse(e.target.result);
          localStorage.setItem('phd_save_import', JSON.stringify(saveData));
          resolve(saveData.state);
        } catch (err) {
          reject(err);
        }
      };
      reader.readAsText(file);
    });
  }
  
  // 获取所有存档
  static getAllSaves() {
    const saves = [];
    for (let i = 0; i < localStorage.length; i++) {
      const key = localStorage.key(i);
      if (key.startsWith('phd_save_')) {
        const slot = key.replace('phd_save_', '');
        const data = JSON.parse(localStorage.getItem(key));
        saves.push({
          slot,
          timestamp: data.timestamp,
          chapter: data.state.chapter,
          playTime: data.state.playTime
        });
      }
    }
    return saves.sort((a, b) => b.timestamp - a.timestamp);
  }
}
```

### 11.3 痕迹触发机制

```javascript
class TraceSystem {
  constructor(gameState) {
    this.state = gameState;
    this.traces = traceSystem.traces;
    this.progress = 0;
  }
  
  // 身体痕迹触发（觉醒时自动触发）
  discoverBodyTrace() {
    // 显示手心特写
    this.showHandCloseup();
    
    // 动画：符文印记逐渐显现
    this.animateRuneMark({
      duration: 2000,
      glowIntensity: 0.3,
      onComplete: () => {
        this.traces.runeMark.discovered = true;
        this.traces.scar.discovered = true;
        this.progress = 1;
        this.updateUI();
      }
    });
    
    // 播放发现音效
    AudioManager.play('discover_trace');
  }
  
  // 物品痕迹触发（触摸石头时）
  discoverItemTrace() {
    // 石头温度效果
    this.animateStoneWarmth({
      temperature: 37,
      duration: 5000,
      onTick: (temp) => {
        // 实时更新温度显示
        this.updateTemperatureUI(temp);
      },
      onComplete: () => {
        this.traces.stoneWarmth.discovered = true;
        
        // 播放海浪声
        this.playOceanSound({
          volume: 0.3,
          fadeIn: 1000,
          duration: 3000,
          fadeOut: 1000,
          onComplete: () => {
            this.traces.oceanSound.discovered = true;
            this.progress = 2;
            this.updateUI();
          }
        });
      }
    });
  }
  
  // 知识痕迹触发（注视符文时）
  discoverKnowledgeTrace() {
    // 符文含义揭示
    this.showKnowledgeReveal({
      rune: 'resonance',
      meaning: '共振',
      duration: 3000,
      onComplete: () => {
        this.traces.runeMeaning.discovered = true;
        this.progress = 3;
        this.updateUI();
        
        // 触发真相揭示
        this.triggerTruthReveal();
      }
    });
  }
  
  // 真相揭示
  triggerTruthReveal() {
    this.state.truthRevealed = true;
    
    // 解锁成就
    AchievementSystem.unlock('resonance');
    
    // 显示结局画面
    this.showEndingScreen({
      title: '共振',
      description: '发现梦不是虚构的，而是跨越维度的连接',
    });
  }
  
  // UI更新
  updateUI() {
    // 更新痕迹进度条
    UI.updateTraceProgress(this.progress);
    
    // 更新符文印记显示
    if (this.traces.runeMark.discovered) {
      UI.showRuneMark(this.traces.runeMark);
    }
  }
}
```

**系统概述**：
游戏会记住玩家之前的选择，在后续剧情中NPC会"记得"你之前的行为，增加沉浸感和真实感。

```javascript
class MemorySystem {
  constructor() {
    this.memoryKey = 'phd_memory';
    this.memory = this.loadMemory();
  }
  
  // 加载记忆
  loadMemory() {
    const data = localStorage.getItem(this.memoryKey);
    return data ? JSON.parse(data) : {
      choices: [],           // 选择历史
      npcInteractions: {},   // NPC互动记录
      visitedScenes: [],     // 访问过的场景
      playerPatterns: {},    // 玩家行为模式
      timestamps: {}         // 时间戳
    };
  }
  
  // 保存记忆
  saveMemory() {
    localStorage.setItem(this.memoryKey, JSON.stringify(this.memory));
  }
  
  // 记录选择
  recordChoice(sceneId, choiceId, choiceText) {
    this.memory.choices.push({
      scene: sceneId,
      choice: choiceId,
      text: choiceText,
      timestamp: Date.now()
    });
    this.saveMemory();
  }
  
  // 记录NPC互动
  recordNPCInteraction(npcId, interactionType, details) {
    if (!this.memory.npcInteractions[npcId]) {
      this.memory.npcInteractions[npcId] = [];
    }
    this.memory.npcInteractions[npcId].push({
      type: interactionType,
      details: details,
      timestamp: Date.now()
    });
    this.saveMemory();
  }
  
  // 获取NPC记忆
  getNPCMemory(npcId) {
    return this.memory.npcInteractions[npcId] || [];
  }
  
  // 检查玩家行为模式
  checkPattern(patternType) {
    // 例如：检查玩家是否总是选择"理性"选项
    const rationalChoices = this.memory.choices.filter(c => 
      c.text.includes('科学') || c.text.includes('物理')
    );
    return rationalChoices.length > this.memory.choices.length * 0.6;
  }
}
```

### 12.3 真实时间机制

**系统概述**：
某些修炼需要真实时间等待，期间屏幕变黑，只能听到海浪声，增加沉浸感和"修炼"的真实感。

**核心实现**：

```javascript
class RealTimeSystem {
  constructor() {
    this.waitingTasks = new Map();
    this.timeBasedEvents = new Map();
  }
  
  // 开始等待任务
  startWaitingTask(taskId, duration, onComplete) {
    const startTime = Date.now();
    const endTime = startTime + duration;
    
    this.waitingTasks.set(taskId, {
      startTime,
      endTime,
      onComplete,
      progress: 0
    });
    
    // 显示等待界面
    this.showWaitingUI(taskId, duration);
    
    // 开始计时
    this.updateProgress(taskId);
  }
  
  // 更新进度
  updateProgress(taskId) {
    const task = this.waitingTasks.get(taskId);
    if (!task) return;
    
    const now = Date.now();
    const elapsed = now - task.startTime;
    const progress = Math.min(elapsed / (task.endTime - task.startTime), 1);
    
    task.progress = progress;
    this.updateProgressUI(taskId, progress);
    
    if (progress >= 1) {
      // 任务完成
      task.onComplete();
      this.waitingTasks.delete(taskId);
      this.hideWaitingUI(taskId);
    } else {
      // 继续更新
      requestAnimationFrame(() => this.updateProgress(taskId));
    }
  }
  
  // 显示等待界面
  showWaitingUI(taskId, duration) {
    // 屏幕变黑
    const overlay = document.createElement('div');
    overlay.id = `waiting-${taskId}`;
    overlay.className = 'waiting-overlay';
    overlay.innerHTML = `
      <div class="waiting-content">
        <div class="waiting-title">修炼中...</div>
        <div class="waiting-progress">
          <div class="waiting-bar" style="width: 0%"></div>
        </div>
        <div class="waiting-time">${this.formatTime(duration)}</div>
        <div class="waiting-hint">闭上眼睛，感受灵气的流动</div>
      </div>
    `;
    document.body.appendChild(overlay);
    
    // 播放海浪声
    audioManager.play('ocean_waves', { loop: true, volume: 0.3 });
  }
  
  // 更新进度UI
  updateProgressUI(taskId, progress) {
    const overlay = document.getElementById(`waiting-${taskId}`);
    if (overlay) {
      const bar = overlay.querySelector('.waiting-bar');
      bar.style.width = `${progress * 100}%`;
    }
  }
  
  // 隐藏等待界面
  hideWaitingUI(taskId) {
    const overlay = document.getElementById(`waiting-${taskId}`);
    if (overlay) {
      overlay.remove();
    }
    audioManager.stop('ocean_waves');
  }
  
  // 格式化时间
  formatTime(ms) {
    const seconds = Math.floor(ms / 1000);
    const minutes = Math.floor(seconds / 60);
    const remainingSeconds = seconds % 60;
    return `${minutes}:${remainingSeconds.toString().padStart(2, '0')}`;
  }
  
  // 注册基于时间的事件
  registerTimeEvent(eventId, triggerTime, callback) {
    this.timeBasedEvents.set(eventId, {
      triggerTime,
      callback
    });
  }
  
  // 检查时间事件
  checkTimeEvents() {
    const now = new Date();
    const currentHour = now.getHours();
    const currentMinute = now.getMinutes();
    
    this.timeBasedEvents.forEach((event, eventId) => {
      if (currentHour === event.triggerTime.hour && 
          currentMinute === event.triggerTime.minute) {
        event.callback();
      }
    });
  }
}
```

### 12.4 多人抉择统计系统

**系统概述**：
在关键抉择后显示"XX%的玩家和你做了相同的选择"，增加社交感和群体认同感。

**数据结构**：

```javascript
class ChoiceStatsSystem {
  constructor() {
    this.statsKey = 'phd_choice_stats';
    this.stats = this.loadStats();
    this.apiEndpoint = 'https://api.phd-adventure.com/stats'; // 可选的后端API
  }
  
  // 加载统计数据
  loadStats() {
    const data = localStorage.getItem(this.statsKey);
    return data ? JSON.parse(data) : {
      global: {},      // 全局统计
      local: {},       // 本地统计
      lastSync: null   // 最后同步时间
    };
  }
  
  // 保存统计数据
  saveStats() {
    localStorage.setItem(this.statsKey, JSON.stringify(this.stats));
  }
  
  // 记录选择
  recordChoice(sceneId, choiceId) {
    const key = `${sceneId}_${choiceId}`;
    
    // 本地统计
    if (!this.stats.local[key]) {
      this.stats.local[key] = 0;
    }
    this.stats.local[key]++;
    
    // 全局统计（如果有后端）
    this.syncGlobalStats(sceneId, choiceId);
    
    this.saveStats();
  }
  
  // 同步全局统计
  async syncGlobalStats(sceneId, choiceId) {
    try {
      const response = await fetch(`${this.apiEndpoint}/choice`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          sceneId,
          choiceId,
          timestamp: Date.now()
        })
      });
      
      if (response.ok) {
        const data = await response.json();
        this.stats.global[`${sceneId}_${choiceId}`] = data.percentage;
        this.stats.lastSync = Date.now();
        this.saveStats();
      }
    } catch (error) {
      // 静默失败，不影响游戏体验
      console.log('Stats sync failed, using local data');
    }
  }
  
  // 获取选择统计
  getChoiceStats(sceneId, choiceId) {
    const key = `${sceneId}_${choiceId}`;
    
    // 优先使用全局数据
    if (this.stats.global[key]) {
      return {
        percentage: this.stats.global[key],
        source: 'global'
      };
    }
    
    // 使用本地数据估算
    const localTotal = Object.keys(this.stats.local)
      .filter(k => k.startsWith(sceneId))
      .reduce((sum, k) => sum + this.stats.local[k], 0);
    
    const localChoice = this.stats.local[key] || 0;
    const percentage = localTotal > 0 ? Math.round((localChoice / localTotal) * 100) : 0;
    
    return {
      percentage,
      source: 'local'
    };
  }
  
  // 显示统计结果
  showStatsUI(sceneId, choiceId, choiceText) {
    const stats = this.getChoiceStats(sceneId, choiceId);
    
    // 创建统计显示
    const statsElement = document.createElement('div');
    statsElement.className = 'choice-stats';
    statsElement.innerHTML = `
      <div class="stats-content">
        <div class="stats-icon">📊</div>
        <div class="stats-text">
          <span class="stats-percentage">${stats.percentage}%</span>的玩家和你做了相同的选择
        </div>
        <div class="stats-source">
          ${stats.source === 'global' ? '（全球数据）' : '（本地数据）'}
        </div>
      </div>
    `;
    
    // 添加到页面
    const choiceContainer = document.querySelector('.choice-container');
    if (choiceContainer) {
      choiceContainer.appendChild(statsElement);
    }
    
    // 动画效果
    setTimeout(() => {
      statsElement.classList.add('visible');
    }, 500);
  }
}
```
