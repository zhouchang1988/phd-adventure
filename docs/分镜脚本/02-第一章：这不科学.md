# 第一章：这不科学 - 分镜脚本

> **时长**：6分钟  
> **节奏**：好奇→尝试→成功→思考  
> **情绪**：怀疑→惊喜→自豪→抉择

---

## 场景1：海边修炼

| 项目 | 内容 |
|------|------|
| **镜头** | 中景 → 谢凡盘腿坐在沙滩上 |
| **画面** | 谢凡按照石头上的说明，盘腿坐在沙滩上，闭眼调整呼吸。月光洒在他身上。 |
| **色调** | 深蓝 #0f172a + 月光白 #f5f5f5 |
| **音效** | 海浪声（循环）、呼吸声 |
| **BGM** | 冥想音乐（轻柔，音量0.2） |
| **时长** | 8秒 |
| **备注** | 建立修炼氛围 |

**角色状态**：
- 姿态：盘腿坐姿，双手放在膝盖上
- 表情：闭眼，专注
- 呼吸：缓慢、有节奏
