# 第五章：踏天 - 分镜脚本

> **时长**：10分钟  
> **节奏**：考验→顿悟→选择→超越  
> **情绪**：敬畏→思考→感动→释然

---

## 场景1：九桥全景

| 项目 | 内容 |
|------|------|
| **镜头** | 远景 → 缓慢环绕 |
| **画面** | 九座桥悬浮在云端，每座桥颜色不同，通向不同的方向。 |
| **色调** | 渐变彩虹 |
| **音效** | 风声、能量嗡鸣声 |

| **备注** | 建立超现实、神圣的氛围 |

## 场景8：最终抉择（杀手级场景）

| 项目 | 内容 |
|------|------|
| **镜头** | 中景 → 谢凡面对平行谢凡 |
| **画面** | 谢凡面临选择，屏幕下方出现三个选项。 |
| **UI** | 选项框从下方滑入 |
| **音效** | 选项出现的"叮"声 |
| **BGM** | 抉择音效 |
| **时长** | 等待玩家选择 |
| **备注** | 这是让玩家"记住一辈子"的核心场景 |

**选项设计**：
```
┌─────────────────────────────────────────┐
│                                         │
│  守桥人："你羡慕他吗？"                  │
│                                         │
├─────────────────────────────────────────┤
│  A. 【羡慕】"我羡慕你。你有稳定的工作，有家庭，有正常的生活。"│
│     → 平行谢凡笑了："但你有修仙，有九桥，有无限可能。"│
│     → 获得：成就【平凡之福】，但失去继续前进的动力│
│  ─────────────────────────────────────  │
│  B. 【不羡慕】"不。我选择了我的路，我不后悔。"│
│     → 平行谢凡点点头："那就好。"         │
│     → 他转身离开，背影渐渐模糊           │
│     → 获得：继续前进，但永远不知道那条路的结局│
│  ─────────────────────────────────────  │
│  C. 【聊聊】"等等。我想和你聊聊。"       │
│     → 平行谢凡笑了："好啊。我也想和你聊聊。"│
│     → 两人坐在桥边，聊了很久             │
│     → 平行谢凡："其实，我们都是对的。只是选择了不同的路。"│
│     → 谢凡："是的。谢谢你。"             │
│     → 平行谢凡："也谢谢你。让我知道，原来我还可以修仙。"│
│     → 两人相视而笑                       │
│     → 获得：成就【两条路】，解锁隐藏剧情 │
└─────────────────────────────────────────┘
```

| **备注** | 简化处理，快速过场 |

**旁白脚本**：
```

"接受不确定性。薛定谔的猫既死又活，你呢？"
→ 你选择：接受自己既是博士也是修仙者

第五桥·自我之桥：
"你不是宇宙的中心。"
→ 你想起那些被拒的简历，笑了

第六桥·联系之桥：
"万物相连。你今天的失败，是明天成功的因。"
→ 你想起那块海边的石头

第七桥·变化之桥：
"唯一不变的是变化。"
→ 你想起从失业博士到修仙者的三年

第八桥·生死之桥：
"生和死只是状态转换。"
→ 你想起物理学的能量守恒定律
```
