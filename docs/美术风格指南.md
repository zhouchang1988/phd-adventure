# 《谢凡的奇幻冒险2.0》美术风格指南

## 1. 风格定义

### 1.1 关键词

- **扁平化**：无阴影、无透视、简洁色块
- **现代感**：干净、留白、呼吸感
- **轻幽默**：色彩明快、不沉重、带点赛博感
- **中国都市**：现代中国城市背景，不是古风仙侠

### 1.2 参考风格

- Linear / Notion 的插画风格
- Stripe 官网的图形设计
- 《Alto's Odyssey》的极简美学
- Dribbble 上的 flat illustration 标签

### 1.3 风格禁忌

- ❌ 不要 3D 渲染
- ❌ 不要过度细节
- ❌ 不要传统水墨/古风
- ❌ 不要暗黑/哥特风
- ❌ 不要日系二次元大眼睛

### 1.4 纯CSS实现方案

**零美术资源，代码即艺术**

所有游戏视觉元素（场景、角色、特效、UI）完全使用HTML+CSS实现，不依赖任何图片资源。

**详细方案**：[纯CSS实现方案](./纯CSS实现方案.md)

**设计原则**：
- **抽象化**：用几何形状和色块表达，不追求写实
- **氛围感**：重点是营造场景氛围，而非细节还原
- **简约美**：参考Linear/Notion的插画风格
- **代码驱动**：所有视觉效果通过CSS控制，便于调整和维护

**优势**：
- 零资源加载，启动速度极快
- 完全可控，所有视觉效果通过代码调整
- 响应式完美，CSS轻松适应不同屏幕尺寸
- 风格统一，不会出现美术资源风格不一致
- 维护简单，修改CSS即可，无需重新设计图片
- 文件体积小，纯代码，无图片资源

## 7. 动画规范

### 7.1 文字动画

```css
/* 打字机效果 */
@keyframes typewriter {
  from { width: 0 }
  to { width: 100% }
}

/* 文字闪烁（用于"点击继续"提示） */
@keyframes blink {
  0%, 100% { opacity: 1 }
  50% { opacity: 0.3 }
}
```

### 7.2 界面动画

```css
/* 场景切换 - 淡入淡出 */
@keyframes fadeIn {
  from { opacity: 0 }
  to { opacity: 1 }
}

/* 选项出现 - 从下滑入 */
@keyframes slideUp {
  from { 
    transform: translateY(20px);
    opacity: 0;
  }
  to { 
    transform: translateY(0);
    opacity: 1;
  }
}

/* 成就弹窗 - 从上滑入 */
@keyframes slideDown {
  from { 
    transform: translateY(-100%);
    opacity: 0;
  }
  to { 
    transform: translateY(0);
    opacity: 1;
  }
}
```

### 7.3 特效动画

```css
/* 灵气波动 */
@keyframes pulse {
  0%, 100% { 
    box-shadow: 0 0 0 0 rgba(59, 130, 246, 0.4);
  }
  50% { 
    box-shadow: 0 0 0 20px rgba(59, 130, 246, 0);
  }
}

/* 屏幕震动 */
@keyframes shake {
  0%, 100% { transform: translateX(0) }
  25% { transform: translateX(-5px) }
  75% { transform: translateX(5px) }
}

/* 海浪效果 */
@keyframes wave {
  0%, 100% { transform: translateX(0) }
  50% { transform: translateX(-20px) }
}
```

### 7.4 动画时长

| 类型 | 时长 | 缓动 |
|------|------|------|
| 文字出现 | 30ms/字 | linear |
| 场景切换 | 300ms | ease-in-out |
| 选项出现 | 200ms | ease-out |
| 弹窗出现 | 300ms | ease-out |
| 特效持续 | 500ms-2s | ease-in-out |

## 11. 痕迹系统视觉设计（终章防白玩机制）

### 11.1 设计理念

痕迹系统是终章"防白玩"设计的视觉核心。通过三层痕迹（身体、物品、知识）的视觉呈现，让玩家感受到"梦不是虚构的"，而是跨越维度的真实连接。

**设计原则**：
- 痕迹应该是"微妙的"，而非"明显的"
- 痕迹应该是"温暖的"，而非"恐怖的"
- 痕迹应该是"诗意的"，而非"直白的"

### 11.2 符文印记设计

**设计概念**：
符文印记是"共振"的视觉符号，代表两个谢凡跨越维度的连接。

```
符号构成
├── 形状：两个重叠的圆形，象征两个世界
├── 线条：柔和的曲线，非几何硬边
├── 中心：一个小小的光点，象征连接点
└── 整体：像指纹，又像声波
```
