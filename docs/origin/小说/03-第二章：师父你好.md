# 第二章：师父你好

三天后，谢凡站在星海大学教职工宿舍楼下。

这是一栋老旧的居民楼，外墙有些斑驳，阳台上晾晒着各色衣物。但那些阳台上摆满了花盆，绿意盎然，给这栋老楼增添了几分生机。

谢凡抬头看着三楼的一个阳台，那里有一个白发老人正在浇花。

正是那晚在海边钓鱼的老人。

这三天里，谢凡一直在修炼。他每天晚上都会按照系统指引，打坐修炼几个小时。灵气在他的体内越聚越多，他的境界也在稳步提升——从凝气期一层，到凝气期二层，再到凝气期三层。

但他知道，光靠自己摸索是不够的。

他需要一个师父。

于是，他开始调查那晚遇到的老人。通过学校的朋友，他打听到了一个消息：教职工宿舍三楼住着一个退休的物理学教授，姓张，据说已经退休几十年了，但看起来还是很精神。

"张教授啊，"朋友说，"他是个怪人。退休了也不搬走，就住在学校里。平时也不怎么出门，就在家里浇花、看书。有人问他为什么不出去旅游，他说'我活了三百岁，什么没见过？'大家都以为他在开玩笑。"

三百岁。

谢凡听到这个数字的时候，心跳漏了一拍。

如果是在三天前，他一定会觉得这是在开玩笑。但现在，他相信了。

他深吸一口气，走上楼去。

门是开着的。

谢凡敲了敲门框，"张教授？"

"进来吧。"里面传来一个苍老但中气十足的声音。

谢凡走进房间，看到张教授正坐在阳台的椅子上，手里拿着一个水壶，正在给一盆兰花浇水。他穿着一件白色的老头衫，脚上趿拉着灰色的拖鞋，看起来和普通的退休老人没什么两样。

但谢凡知道，这个老人不普通。

"你来了。"张教授转过头来，笑眯眯地看着他。

"您认识我？"谢凡有些惊讶。

"我认识那块石头。"张教授放下水壶，"它等了三百年，终于等到一个能用物理学理解灵气的人。"

谢凡的心跳加速了。"请问……您是？"

"我姓张，你可以叫我张教授。"老人站起来，走进屋里，"退休前教量子物理的。"

"……所以您也是修仙者？"谢凡跟在后面，小心翼翼地问。

张教授笑了起来，"三百年前是散修，现在是退休老头。社保医保都有，就是退休金不太够。"

谢凡不知道该怎么接话。他环顾四周，房间里不大，但书架上摆满了书，还有各种奇怪的仪器——有些他认识，有些他完全没见过。

"坐吧。"张教授指了指客厅的沙发。

谢凡坐下来，张教授给他倒了一杯茶。茶水是淡绿色的，散发着一股奇异的清香。

"这是灵茶，"张教授说，"对修炼有好处。"

谢凡端起茶杯，小心翼翼地喝了一口。茶水入口，一股温暖的能量顺着喉咙流遍全身，让他精神一振。

"好茶。"他由衷地赞叹。

张教授笑了笑，然后表情变得严肃起来。"你想拜我为师？"

谢凡愣了一下，然后点了点头。"是的。"

"先回答三个问题。"张教授竖起三根手指。

谢凡坐直了身体，"请说。"

"第一个问题：灵气的本质是什么？"

谢凡思考了片刻。这个问题他这几天一直在想，也有了自己的答案。

"一种未知的基本粒子，"他说，"它不遵循已知的物理定律，但可以被数学描述。它可能是某种玻色子，或者是某种我们尚未发现的能量形式。"

张教授点了点头，没有评价。"第二个问题：为什么修仙者要隐藏身份？"

谢凡想了想，"保护普通人？如果修仙者公开存在，一定会引起社会动荡。而且，如果被研究机构知道，可能会被抓去做实验。"

张教授又点了点头。"第三个问题：你为什么想修仙？"

这个问题让谢凡沉默了。

他想起了那些拒信，想起了那些面试官的表情，想起了自己现在的处境。他想修仙，是因为走投无路吗？还是因为真的对这种未知的力量感兴趣？

"我想理解世界，"谢凡终于开口了，"物理学让我理解了宏观世界的规律，量子力学让我理解了微观世界的规律。但灵气……它是一种全新的力量，一种我从未见过的力量。我想理解它，想掌握它，想用它来解释那些物理学无法解释的现象。"

张教授看着他，眼中闪过一丝赞赏。

"不错，"他说，"有科学家的潜质。"

谢凡松了一口气。

"但是，"张教授话锋一转，"光有理论是不够的。修仙需要实践，需要经验，需要一个引路人。"

他站起来，走到书架前，拿下一本书，递给谢凡。

书的封面上写着：《修仙入门（第300版）》。

"这本书你拿去看，"张教授说，"有问题再来找我。"

谢凡接过书，翻开第一页。上面密密麻麻地写满了文字，还配有各种图表和公式。看起来像是一本教科书，但内容却是他从未见过的。

"谢谢您。"谢凡由衷地说。

张教授摆了摆手，"先别急着谢。我还有一个问题想问你。"

"什么问题？"

"你愿意正式拜入守夜人吗？"

谢凡愣住了。"守夜人？"

"一个维护两界平衡的组织，"张教授解释道，"修仙界和凡人界之间的平衡。我们负责处理那些修仙界的问题，同时保护普通人不被修仙者伤害。"

谢凡想起了那晚在海边遇到的老人，想起了石头上的文字，想起了系统界面。这一切都太巧合了，像是被安排好的一样。

"您是守夜人的人？"他问。

张教授点了点头，"我是守夜人的长老之一。那块凝气石，是我放在海边的。"

谢凡瞪大了眼睛。"您……您是故意等我的？"

"不是等你，"张教授笑了笑，"是等一个能用物理学理解灵气的人。三百年了，终于等到了。"

谢凡沉默了。

他想起了那晚在海边的偶遇，想起了老人说的那句"那块石头不错，留着吧"。原来这一切都不是巧合，而是被安排好的。

"我……"他犹豫了一下，"我能考虑一下吗？"

"当然可以，"张教授站起来，"这是一辈子的决定，不能草率。"

他走到门口，"对了，还有一件事。"

"什么事？"

"我还有一个学生，叫赵雪。比你早入门三个月。你们可以多交流。"

谢凡点了点头，"好的。"

他正要离开，突然听到一声猫叫。

"喵~"

谢凡低头一看，只见一只白色的流浪猫正蹲在窗台上，用一双蓝色的眼睛看着他。那只猫的毛色纯白，没有一丝杂色，看起来很高贵。

"这是小白，"张教授说，"有灵智的猫。喜欢蹭灵气。"

小白跳下窗台，走到谢凡脚边，用头蹭了蹭他的腿。然后，它纵身一跃，跳到了谢凡的肩膀上。

"它……能帮我修炼？"谢凡有些惊讶。

"不能，"张教授笑了笑，"但它会在你修炼时睡觉。据说能吸收溢出的灵气。"

"……所以是吉祥物？"

"可以这么理解。"

谢凡看着肩膀上的小白，小白也看着他，蓝色的眼睛里闪烁着智慧的光芒。

"好吧，"谢凡叹了口气，"欢迎加入我的修仙之旅。"

小白"喵"了一声，似乎很满意这个回答。

谢凡抱着小白，走出了教职工宿舍。阳光照在他身上，温暖而明亮。

他看着手里的《修仙入门》，看着肩膀上的小白，心中涌起一股复杂的情绪。

他的生活，真的要变得不一样了。

*第二章完*
