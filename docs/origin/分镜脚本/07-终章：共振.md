# 终章：共振 - 分镜脚本

> **时长**：5分钟  
> **节奏**：觉醒→发现→顿悟→结局  
> **情绪**：困惑→惊讶→感动→释然

---

```

你把石头拿出来，放在手心。
石头的温度渐渐消失，变回普通的石头。

但在温度消失的瞬间，你听到了海浪声——
不是此刻平静的海面，

谢凡："等等……这个声音……"

你记得这个声音。
在梦里，每次修炼时，你都会听到这个声音。

谢凡："不可能。梦里的声音怎么会……"
```

## 场景14：发现知识痕迹

| 项目 | 内容 |
|------|------|
| **镜头** | 特写 → 谢凡手心的符文 |
| **画面** | 谢凡低头看着手心的符文印记。他突然"知道"了它的含义。 |
| **特效** | 符文发光 |
| **音效** | 顿悟音效 |
| **BGM** | 神秘音乐达到高潮 |
| **时长** | 15秒 |
| **备注** | 第三层痕迹：知识痕迹 |

**对话脚本**：
```
你突然"知道"了它的含义。

不是想起来的，是"知道"的——
就像你知道1+1=2一样，
不需要回忆，它就在那里。

谢凡："这个符文……是'共振'的意思。"

你愣住了。

谢凡："等等。我为什么会知道这个？我从来没学过符文。这是……梦里的知识？"

你盯着那个符文，试图回忆更多。
但记忆是模糊的——
你记得修炼、记得突破、记得有人叫你"师兄"……
但具体的人脸、地点、事件，都像是隔着一层雾。

只有这个符文，清晰地刻在你的手心，
也刻在你的记忆里。
```

```
谢凡："而这个符文……是他留给我的。
跨越维度的……一封信。"
```

## 场景16：结局

| 项目 | 内容 |
|------|------|
| **镜头** | 中景 → 谢凡站起来 |
| **画面** | 谢凡把鹅卵石放进口袋，站起来。 |
| **对话** | 见下方对话脚本 |
| **表情** | 坚定、释然、微笑 |
| **音效** | 无 |
| **BGM** | 感动音乐达到高潮 |
| **时长** | 30秒 |
| **备注** | 最终结局 |

**对话脚本**：
```
你把鹅卵石放进口袋，站起来。

你不再迷茫，不再自我怀疑。
你知道：梦中的经历是真实的，只是发生在另一个世界。
你可以用修仙梦境里的"第一性原理"重新审视自己的处境。

谢凡："我不知道你是谁。但我知道一件事：
你在梦里教我的东西，是真的。"

你看着大海，笑了。

谢凡："谢谢你，另一个我。"

你转身，往回走。
手心的符文在阳光下微微发光。

【游戏结束】
```
