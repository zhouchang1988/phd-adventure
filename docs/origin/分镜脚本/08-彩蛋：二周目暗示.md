# 彩蛋：二周目暗示 - 分镜脚本

> **时长**：1分钟  
> **触发条件**：完成一周目后，重新开始游戏  
> **节奏**：熟悉→惊讶→选择  
> **情绪**：怀旧→好奇→期待

---

## 场景1：再次来到海边

| 项目 | 内容 |
|------|------|
| **镜头** | 远景 → 海边夜晚 |
| **画面** | 你再次来到海边，场景与序章相同，但气氛略有不同。 |
| **色调** | 深蓝 #0f172a + 月光白 #f5f5f5 |
| **音效** | 海浪声（循环，音量0.4） |
| **BGM** | 怀旧音乐（音量0.2） |
| **时长** | 8秒 |
| **备注** | 建立怀旧氛围，玩家会感觉"似曾相识" |

### D. 设计意图

**彩蛋目的**：
- 给愿意多周目的玩家额外奖励
- 增加游戏深度和重玩价值
- 暗示更多隐藏内容
- 建立"二周目"的概念

**触发条件**：
- 必须完成一周目
- 必须重新开始游戏
- 必须再次来到海边
- 必须捡起石头

**隐藏信息作用**：
- 暗示二周目会有新内容
- 增加玩家好奇心
- 建立"多周目"的游戏机制
- 给玩家"探索"的动力
