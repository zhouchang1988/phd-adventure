# 序章：海边的石头 - 分镜脚本

> **时长**：5分钟  
> **节奏**：慢→快→悬念  
> **情绪**：孤独→好奇→惊讶→抉择

---

## 场景8：第一个抉择

| 项目 | 内容 |
|------|------|
| **镜头** | 近景 → 谢凡手握石头 |
| **画面** | 谢凡看着手里的石头，思考。屏幕下方出现三个选项。 |

| **音效** | 选项出现的"叮"声 |

**选项设计**：
```

│  ─────────────────────────────────────  │

└─────────────────────────────────────────┘
```

**选项样式**：
- A：左边蓝色竖线（理性）
- B：左边绿色竖线（随性）
- C：左边紫色竖线（学术）
