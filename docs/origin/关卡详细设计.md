# 《谢凡的奇幻冒险2.0》关卡详细设计

## 设计目标

- **总时长**：55-65分钟（含阅读和思考）
- **关卡数量**：7个主线关卡 + 1个隐藏彩蛋
- **NPC数量**：12个主要NPC + 若干路人NPC
- **选择点**：每关2-3个关键选择
- **节奏**：前快后慢，终章留白让玩家回味

## 序章：海边的石头（5分钟）

### 场景描述
> 深夜，星海市某海滩。你——谢凡，28岁，理论物理学博士，刚收到第47封拒信。
> 海风吹乱了你的头发，手机屏幕的光照亮你疲惫的脸。
> 你漫无目的地踢着沙子，突然脚下一硌……

### 剧情节点

**节点1-1：发现石头**（1分钟）
```
你低头一看，是一块拳头大小的石头，表面有奇异的纹路，在月光下微微发亮。

谢凡内心OS：
A. "这是什么放射性物质？需要报警吗？"（理性线）
B. "好漂亮的石头，带回去当摆件。"（随性线）
C. "等等，这个纹路……像是某种分形结构？"（学术线）

[无论选什么，都会捡起石头]
```

**节点1-2：海边偶遇**（1分钟）
```
你正要离开，发现不远处有个人影。

一个穿着老头衫、拖鞋的白发老人正坐在礁石上钓鱼。

老人："年轻人，这么晚了还不回家？"

谢凡："睡不着。"

老人："我也是。退休了反而失眠。你是附近的？"

谢凡："不是，我来投简历的。没找到工作。"

老人看了你一眼，目光落在你手里的石头上。

老人："那块石头不错。留着吧。"

[自动播放，暗示张教授]
```

**节点1-3：石头发光**（1分钟）
```
你往回走的路上，石头突然发出柔和的蓝光。

谢凡："卧槽！真的放射性物质？！"

光芒中浮现出一行文字：
"凝气石——修仙入门辅助工具，有效期3000年，已过期2999年。"

谢凡："……这是什么劣质营销短信？"

[自动播放，无选择]
```

**节点1-4：第一个抉择**（2分钟）
```
石头的光芒渐渐稳定，你感觉到一股奇异的暖流从手心传来。

此刻，你会：

A. 【理性】把石头交给科研机构
   → 触发：第二天去科研所，遇到守夜人成员
   → 石头被收走，但灵气种子已激活
   → 张教授出现，邀请加入守夜人
   → 进入"体制内修仙"路线
   
B. 【好奇】按照石头上的说明尝试
   → 触发：进入第一章
   → 旁白："你盘腿坐在沙滩上，按照说明调整呼吸。三分钟后，你成功感应到了灵气。也可能是腿麻了。"
   
C. 【社恐】先在网上搜搜有没有人遇到过类似情况
   → 触发：搜到一堆骗子广告，但其中一条帖子引起你注意
   → 旁白："发帖人'守夜人老张'：最近灵气异常增多，有缘人若捡到凝气石，请联系我。"
   → 进入第一章，但会遇到老张
```

**设计意图**：快速建立角色性格，第一个选择就让玩家明确"我是哪种谢凡"

## 第一章：这不科学（6分钟）

### 场景描述
> 你（可能）在海边尝试了修仙。（可能）成功了。
> 现在你面临一个严肃的问题：这到底是不是真的？

### 剧情节点

**节点2-1：灵气感应**（1分钟）
```
你闭上眼睛，调整呼吸。

三分钟后——

谢凡："等等，这个能量波动频率……是6.626×10^-34焦耳·秒？这不是普朗克常数吗？"

旁白：你成功感应到了灵气。物理学博士的执念让你把修仙变成了实验室报告。

谢凡："我需要更多数据。这个样本量太小了。"

[自动播放]
```

**节点2-2：系统激活**（1分钟）
```
石头的光芒突然增强，一个半透明的界面出现在你面前：

╔═══════════════════════════════════════╗
║          【修仙系统 v2.0】            ║
╠═══════════════════════════════════════╣
║  宿主：谢凡                           ║
║  境界：凡人（未入门）                  ║
║  灵力：0/100                          ║
║  神识：15（博士加成+10）               ║
║  悟性：85（学霸专属）                  ║
║  科理值：99（隐藏属性）                ║
║                                       ║
║  【当前任务】                          ║
║  → 感应灵气（已完成）                  ║
║  → 凝气成功（0/1）                    ║
╚═══════════════════════════════════════╝

谢凡："这个UI……是用什么框架写的？"

[自动播放]
```

**节点2-3：凝气修炼**（2分钟）
```
你按照系统的指引，尝试凝聚灵气。

第一次尝试：失败。灵气从指缝溜走。
第二次尝试：失败。灵气在丹田转了一圈跑了。
第三次尝试：……

谢凡："等等，我换个思路。"

你开始用流体力学的方程描述灵气流动，用量子隧穿效应解释突破……

叮！【凝气成功】

系统提示：恭喜宿主突破至凝气期一层！获得称号"理论修仙者"。

谢凡："原来修仙就是解微分方程啊，早说嘛。"

[自动播放]
```

**节点2-4：第二个抉择**（2分钟）
```
你成功凝气了。现在你面临一个选择：

A. 【记录】写一篇论文《论灵气的量子力学本质》
   → 触发：论文被当成民科，但引起"守夜人"注意
   → 获得：守夜人线索+1
   
B. 【保密】谁也不告诉，继续偷偷修炼
   → 触发：独自修炼，效率较低但安全
   → 获得：隐秘+1
   
C. 【分享】在学术论坛匿名发帖讨论
   → 触发：被当成疯子，但遇到一个懂行的回复
   → 获得：潜在盟友+1
```

**设计意图**：展示"科学修仙"的核心玩法，让玩家体验用物理解释修仙的乐趣

## 第二章：师父你好（10分钟）

### 场景描述
> 不管你选择了哪条路，你都遇到了一个自称"守夜人"的老头。
> 他说要收你为徒。你有很多问题想问。
> 在这里，你还会遇到一些重要的伙伴。

### 剧情节点

**节点3-1：遇见老者**（2分钟）
```
场景：星海大学教职工宿舍（老破小）

一个穿着老头衫、拖鞋的白发老人正在浇花。
——正是海边钓鱼的那位。

老者："你来了。"

谢凡："您认识我？"

老者："我认识那块石头。它等了300年，终于等到一个能用物理学理解灵气的人。"

谢凡："请问……您是？"

老者："我姓张，你可以叫我张教授。退休前教量子物理的。"

谢凡："……所以您也是修仙者？"

老者："三百年前是散修，现在是退休老头。社保医保都有，就是退休金不太够。"

[自动播放]
```

**节点3-2：拜师考验**（3分钟）
```
张教授："想拜我为师？先回答三个问题。"

问题1：灵气的本质是什么？
A. "一种未知的基本粒子"（正确）
B. "暗能量的变体"（部分正确）
C. "我不知道"（诚实，+悟性）

问题2：为什么修仙者要隐藏身份？
A. "避免被研究"（功利）
B. "保护普通人"（正义）
C. "懒得解释"（真实）

问题3：你为什么想修仙？
A. "找到工作"（现实）
B. "理解世界"（理想）
C. "来都来了"（佛系）

[根据选择，张教授给出不同评价]
```

**节点3-3：遇见赵雪**（2分钟）
```
拜师结束后，张教授带你参观他的"工作室"——其实就是客厅。

角落里坐着一个年轻女生，正在看一本《量子力学导论》。

张教授："这是我另一个学生，赵雪。比你早入门三个月。"

赵雪抬头看你："你就是那个用物理学修仙的人？张老师说了一周了。"

谢凡："你也是物理学专业的？"

赵雪："天体物理。我在研究灵气和暗物质的关系。"

张教授："你们俩可以多交流。我老了，脑子转不动了。"

[自动播放，建立学术伙伴关系]
```

**节点3-4：灵猫小白**（1分钟）
```
你正要离开，一只白色流浪猫跳上窗台。

张教授："这是小白。有灵智的猫。喜欢蹭灵气。"

小白看了你一眼，跳到你肩膀上。

系统提示：【灵猫小白】成为你的伙伴。修炼时灵气吸收+5%。

谢凡："它……能帮我修炼？"

张教授："不能。但它会在你修炼时睡觉。据说能吸收溢出的灵气。"

谢凡："……所以是吉祥物？"

张教授："可以这么理解。"

[自动播放，获得宠物]
```

**节点3-5：第三个抉择**（2分钟）
```
张教授："最后一个问题——你愿意正式拜入守夜人吗？"

A. 【拜师】"师父在上，请受徒儿一拜！"
   → 触发：正式拜师，获得系统指导
   → 获得：师父好感+10，守夜人声望+5
   
B. 【自学】"我想先自己研究研究。"
   → 触发：张教授给你一本《修仙入门（第300版）》
   → 获得：自由度+1，但后续需要自己摸索
   
C. 【合同】"我们签个合同吧，明确双方权利义务。"
   → 触发：张教授愣住，然后大笑
   → 张教授："三百年了，终于遇到一个比我还较真的！"
   → 获得：隐藏剧情线索+1
```

**设计意图**：建立师徒关系，引入伙伴NPC，展现"修仙也要交社保"的幽默设定

## 第三章：双重生活（15分钟）

### 场景描述
> 你开始了一边修仙一边找工作的日子。
> 白天投简历、面试，晚上打坐修炼。
> 生活中各种人和事不断涌现——房东催租、同学介绍相亲、面试官刁难……
> 修仙界也不平静，你遇到了一个落魄的修士。

### 剧情节点

**节点4-1：房东王阿姨**（2分钟）
```
【周一早上】

你正在修炼，门被拍响了。

王阿姨："小谢！房租该交了！拖了两周了！"

谢凡："阿姨，我下周一定……"

王阿姨："你每个月都说下周！你一个博士，怎么连房租都交不起？"

谢凡："我在研究一个新项目……"

王阿姨："研究什么？研究怎么不交房租？"

你灵机一动——

A. 【坦白】"阿姨，我在修仙。"
   → 王阿姨："你是不是压力太大了？阿姨给你下碗面。"
   → 获得：一碗面，王阿姨好感+1
   
B. 【撒谎】"我找到工作了，下个月发工资就交。"
   → 王阿姨："真的？什么公司？"
   → 需要继续编，50%概率被识破
   
C. 【转移】"阿姨，您最近身体怎么样？我帮您看看？"
   → 用神识扫描，发现王阿姨有轻微风湿
   → 获得：王阿姨好感+3，解锁隐藏剧情

[展示现实压力]
```

**节点4-2：同学李明**（2分钟）
```
【周一下午】

大学同学李明发来微信。

李明："凡哥，最近怎么样？我这边有个内推机会，你要不要试试？"

李明现在是某大厂程序员，月薪30k，经常996。

谢凡："什么岗位？"

李明："飞机设计工程师。你不是学物理的吗？航空航天很合适的。"

李明："对了，我妈同事的女儿也在星海，要不要认识一下？"

A. 【接受内推】"行，简历发你。"
   → 获得：面试机会+1
   
B. 【接受相亲】"照片先看看？"
   → 获得：相亲支线开启
   
C. 【都接受】"都可以，谢谢老李。"
   → 获得：面试机会+1，相亲支线开启
   
D. 【都拒绝】"我再想想。"
   → 李明："你别想太多了，先干着呗。"
   → 获得：无

[引入友情线]
```

**节点4-3：面试官老周**（3分钟）
```
【周二】

你去一家科技公司面试。

面试官老周是CTO，秃顶，眼神锐利。

老周："谢凡是吧？理论物理博士？为什么想转行？"

谢凡："我想……用物理学的方法解决实际问题。"

老周："哦？比如？"

你想起修仙——

A. 【诚实】"比如……能量转换和信息处理？"
   → 老周："有意思，展开说说。"
   → 获得：老周好感+5
   
B. 【套路】"比如机器学习和数据建模。"
   → 老周："简历上写的，我知道。我想听点新的。"
   → 获得：老周好感+0
   
C. 【大胆】"比如……如何让人类突破认知边界？"
   → 老周沉默了很久
   → 老周："你是我今年面试过最有意思的人。明天来上班。"
   → 获得：直接offer

[职场线展开]
```

**节点4-4：小偷/林风**（2分钟）
```
【周三晚上】

你在街上遇到一个小偷。

系统提示：是否使用修仙能力？

   → 旁白："你想起师父说过，修仙者不能随意暴露身份。"
   
C. 【跟踪】暗中跟踪小偷
   → 触发：发现小偷住在一个破旧地下室
   → 小偷发现你："你是谁？"
   → 你发现他身上有微弱灵气

[选择C触发支线]
```

**节点4-5：落魄修士林风**（2分钟）
